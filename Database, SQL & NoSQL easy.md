## What is a relational database? What is SQL?
A relational database is a system that stores data in a tabular format with rows and columns. The word 'relational' means we can join or relate two tables together using common columns.
SQL stands for Structured Query Language. We use it to communicate with the database to perform actions like fetching and updating data, or creating the tables and records.

## What is a primary key? Foreign key? Unique constraint?
A primary key is used to identify the exact record. Let's say two records have the same values in all the columns, but we want to update or delete one of them. There needs to be something unique, right? That's why we use a primary key to uniquely identify a specific row in a table.
A unique constraint can be applied on any column of the table. It forces the column to have unique values, for example, email IDs or mobile numbers.
Coming to the foreign key, we use it to relate two tables. We add one column in one table and point it to the primary key of the other table so that they are in a relationship.
