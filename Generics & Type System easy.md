## What are generics, and why are they useful?

> Generics allow types to be passed as parameters when defining classes, interfaces, and methods:
> * **Compile-Time Type Safety:** The compiler verifies type constraints at build time, preventing accidental insertions of wrong types.
> * **Elimination of Explicit Casts:** Removes repetitive manual casting and prevents runtime `ClassCastException`.
> * **Reusability:** A single algorithm or data structure can operate uniformly across different object types.
> * **Implementation:** Implemented via **Type Erasure**, where the compiler validates types, inserts safe casts, and strips the type parameters so the bytecode remains backward-compatible."
